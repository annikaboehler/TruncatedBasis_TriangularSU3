# Truncated Basis Agent Team

This directory contains a project-specific agent team for the
`TruncatedBasis_TriangularSU3` repository.

The goal is to split work cleanly between:

- paper-level physics interpretation,
- Honeycomb SU(2) solver work,
- Honeycomb symmetry debugging,
- Triangular SU(3) basis construction,
- sc-cc channel-coupling logic,
- reproducibility and plotting.

The files in this directory are written so they can be:

- used directly as project documentation,
- pasted into an agent builder as instructions,
- adapted into Codex subagent prompts.

## Team Files

- `team-manifest.yaml`: high-level team definition, scopes, and handoff graph.
- `physics-foundations.md`: paper-to-code physics translator.
- `honeycomb-core.md`: core Honeycomb SU(2) solver agent.
- `honeycomb-symmetry-debugger.md`: C3, gauge, and rotation-debug agent.
- `su3-basis-builder.md`: Triangular SU(3) basis and Hamiltonian agent.
- `channel-coupling.md`: sc-cc overlap and effective coupling agent.
- `numerics-and-repro.md`: run hygiene, plotting, and reproducibility agent.

## Recommended Usage

1. Start `physics-foundations` when a change depends on the meaning of
   geometric strings, mesons, sc/cc channels, or which square-lattice
   concepts survive on honeycomb / SU(3).
2. Use `honeycomb-core` for production solver changes in `HoneycombSU2/`.
3. Use `honeycomb-symmetry-debugger` when the issue involves C3 phases,
   degenerate subspaces, orbit transport, or overlap consistency.
4. Use `su3-basis-builder` for basis generation, three-color Neel
   bookkeeping, and Triangular SU(3) Hamiltonian work.
5. Use `channel-coupling` when sc-to-cc matrix elements or overlap
   conventions are the main question.
6. Use `numerics-and-repro` for scripts, result paths, figures,
   parameter manifests, and regression workflows.

## Shared Terminology

- `geometric string`: the trail of displaced background spins/colors left by
  dopant motion.
- `truncated string basis`: the cutoff Hilbert/Krylov space generated by
  repeated hopping up to a maximum string length.
- `sc`: spinon-chargon channel, or the one-hole magnetic-polaron-like sector.
- `cc`: chargon-chargon channel, or the tightly bound two-hole sector.
- `meson`: a confined parton composite with internal ro-vibrational structure.
- `Trugman loop`: a loop-equivalent string process that can modify dispersion.

## Current Project State

- `HoneycombSU2/` is the more mature branch and already produces saved
  dispersions, overlaps, and figures.
- `HoneycombSU2/` is also under active C3 debugging, with several dedicated
  debug directories.
- `TriangularSU3/` contains the conceptual SU(3) extension, but its overlap
  pipeline is not yet fully consolidated.
- The paper logic comes from the three root manuscripts:
  `main copy.tex`, `Magnons_AFM-arxiv.tex`, and `main.tex`.
